# Razer Naga X keymap protocol

Device: USB `1532:0096`, firmware v1.0. Device file: [`razer-naga-x.jsonc`](../razer-naga-x.jsonc).

> Generated by `opensynapse protocol` from the device file and read-only queries to the mouse. Everything marked TODO needs someone who tested the mouse, see [PROTOCOL.md](../../PROTOCOL.md).

How it was found: 

Probe.py was necessary to find the information. Init could not successfully complete because it probes each interface and caused the mouse to disconnect/reconnect and the correct interface (3) would be reassigned a different path in hidraw before it could complete.

## Transport

Interface 3, transaction id `0x1f`.

## Button ids

## DPI

Current DPI 1800 x 1800, stages 1800 (active: 1), max 18000 from the device file.

## Action encoding

I verified all thumb buttons, mouse clicks, scroll wheel and DPI switch working. I could not verify mouse wheel click, due to this being physically broken on my mouse and why I use the dpi switch as middle click.
